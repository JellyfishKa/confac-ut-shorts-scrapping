# Передача сюжета и реплик в дальнейшую обработку

## Сейчас

`POST /api/story` получает публичную YouTube-ссылку и возвращает `{url, model, story}`. Это описание видео от Gemini, а не проверенная транскрипция. `POST /api/download` отдельно сохраняет MP4 выбранного ролика. Эти действия не связаны автоматически.

## Следующий маленький этап

Добавить распознавание речи для уже выбранного MP4 или предоставленного аудиофайла. Сначала проверить один короткий ролик вручную. Результат хранить отдельно от описания видео и метрик:

```json
{
  "source_url": "https://www.youtube.com/shorts/VIDEO_ID",
  "language": "ru",
  "segments": [
    {"start_seconds": 1.2, "end_seconds": 3.8, "speaker": "spk_1", "text": "Распознанная реплика"}
  ]
}
```

`speaker` может быть `null`, если разделение говорящих не включено. Сегменты требуют просмотра и исправления перед публикацией как цитат. Формат выше — проект контракта, не действующий API.

Два подхода к получению реплик:

- [Gemini 3.5 Transcribe](https://ai.google.dev/gemini-api/docs/transcribe): загрузка аудио в Gemini Files API, затем транскрипция с метками говорящих и таймкодами. Использует тот же сервис ключей Gemini, но отдельный вызов и квоту.
- [Whisper](https://github.com/openai/whisper): локальное распознавание речи из файла. Для разделения говорящих и более точных таймкодов понадобится дополнительный инструмент, например [WhisperX](https://github.com/m-bain/whisperX).

После проверки транскрипта можно экспортировать SRT и передать `MP4 + SRT` в [AutoClip CLI](https://github.com/zhouxiaoka/autoclip/blob/main/README-EN.md). AutoClip сейчас не установлен как часть этого приложения и его результат не следует смешивать с `story`: первый создаёт клипы, второй описывает исходный ролик.

## Критерий готовности будущей интеграции

Для одного короткого ролика приложение показывает хронологию сцен и отдельно распознанные реплики с таймкодами; пользователь может поправить текст и выгрузить SRT. Перед запуском AutoClip пользователь выбирает исходный MP4 и проверенный SRT. До этого момента кнопка AutoClip в интерфейсе не нужна.
