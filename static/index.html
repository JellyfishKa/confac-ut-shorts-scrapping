Сюжет выбранного видео

Gemini описывает увиденное и услышанное в ролике. Реплики в таком описании могут быть пересказом: для точных слов и таймкодов понадобится отдельная расшифровка речи.

Интерпретация метрик

Предварительный отбор выполняется по метаданным, поэтому большая часть кандидатов может быть оценена без скачивания исходных видео.

Views/h — средняя скорость набора просмотров с момента публикации. Δ views/h — фактическая скорость между двумя snapshot'ами. Breakout — отношение просмотров к числу подписчиков канала.

ComfyUI integration

Кнопка Comfy JSON формирует стабильный manifest без обязательного MP4. Поля manifest можно сопоставить с inputs любого API-format workflow. Если workflow требует исходное видео, MP4 скачивается только для выбранного кандидата.
